## Markdown Formatting Guidelines

When creating or editing Markdown files:

- **Enforce a hard wrap at 82 characters.** No line should exceed this limit.
- **Start each statement on a new line.** Do not combine multiple statements on
  the same line.
- **Use two trailing spaces for explicit line breaks.**
- **Use a blank line to separate paragraphs.**
- **Preserve Markdown syntax and readability** when wrapping text.
