# Project Agent Guidelines

## Project Context

The project foundations are essential context for understanding HtmlFlow's
purpose, design principles, terminology, and intended behavior. Before making
changes, consult the relevant foundations and other documentation under
[`context/`](context/), especially the [architecture decision records](context/adr/).
Use the foundations as the baseline for interpreting the code and evaluating
proposed changes; do not assume that code alone captures the intended design.

Keep foundation guidance accurate for the **current HtmlFlow release**. When
working on or updating foundations, verify that descriptions of behavior,
features, and conventions correspond to that release; do not carry forward
outdated assumptions from earlier releases or treat future proposals as
current behavior.

Check each ADR's status: a proposed or open ADR records a direction under
discussion, not an approved decision. Do not present it as settled or implement
it as an accepted requirement without confirmation.
