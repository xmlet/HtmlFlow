This release consolidates work on **stronger micro-frontend (MFE) support** and
introduces **value-based rendering** through continuations compiled to JVM
bytecode.  
Across this development cycle, the project strengthened micro-frontend support
and introduced a new value-oriented templating approach.

### Micro-frontend support hardening

The [MFE area](/docs/core-concepts#micro-frontends) received a significant
quality pass:

* expanded MFE test coverage and refactoring;
* E2E tests for MFE behavior;
* script integrity E2E checks;
* engine updates and minification adjustments.

### New value-based rendering API (slot-style bindings)

A value-based alternative to large `dynamic()` blocks.  
You can now express model bindings directly in the template shape with methods
such as:

- `textOf(...)`, `rawOf(...)`
- `attrOf(...)`, `attrOfNullable(...)`
- `intOf(...)`, `longOf(...)`, `doubleOf(...)`, `boolOf(...)`

This design keeps static HTML fragments pre-encoded and injects only
model-derived values at render time.

Also extends the value model with control-flow builders:

- `whenOf(...)` for conditional sections
- `forEachOf(...)` for model-driven iteration
- `forEachIndexedOf(...)` for indexed iteration

These APIs make common dynamic patterns explicit and composable while keeping
templates close to their static HTML structure.

The latest ADR, `context/adr/2026-0001-model-slot-builder.md`, describes the
rationale behind this feature.
